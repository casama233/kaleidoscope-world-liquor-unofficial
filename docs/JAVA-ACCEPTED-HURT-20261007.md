# Accepted combat feedback and source critical dimensions

Reference: current author World Liquor NeoForge1.21.1 **1.1.11 / CF9066406**, LivingDamage.Pre elbow/DoubleDamage hooks and official Minecraft1.21.1 ServerPlayer.crit. A canceled IncomingDamage does not reach the source damage-pre sound hook. Native before-hurt still allows another addon to cancel after World Liquor, so an unconditional deferred playSound was a logic bug.

One transient AcceptedHurtFeedback decision now gates both source audio and critical bursts. It waits for the matching native after-hurt cause/owner/projectile/damage, observes the final cancellation flag and removes the row at settlement. Multiple callbacks on the same before event are preserved; an invalid cosmetic callback is isolated from the others. No health/damage changes or dynamic properties are used by this feedback gate. Original source sound position/dimension/options are captured at the before hook, so moving/removing the actor does not redirect the original sound.

Player.crit broadcasts in the source player's server level and clients there resolve the target entity ID. If a recent player credit is in another dimension, those clients cannot resolve the old-level target. Production critical calls now pass the actual credited/current player and suppress that wrong-dimension particle path. The double-damage sound still plays at its credited actor, as the author source does.

**Still open:** same-dimension observer tracking is not exactly reproduced by Dimension.spawnParticle. ServerPlayer.crit uses broadcastAndSend(attacker, AnimatePacket(target,4)), whose tracking/visibility ranges differ from arbitrary target-dimension broadcasts. Native ClientSystemInfo.maxRenderDistance is the device maximum, not the selected Java/server tracking state; do not use it or a guessed fixed radius as exact equivalence. Network/client render, density/lighting/material/precision and full source damage/cooldown stages remain pending. This batch does not claim every logic bug eliminated or100% parity.

Evidence:40 related program regression groups include production later-cancel/native-reject, source-position/options, multiple callbacks/failure isolation and cross-dimension critical routing. Real native mobs with controlled SDK snapshots execute production hurt callbacks: accepted elbow delivers once/damage4, canceled elbow delivers0/damage0, rejected native hit delivers0/damage0, prior-owner double delivers once/damage8, canceled double delivers0/damage0. The shared native critical requests remain48 in the deterministic centered accepted sample and0 for canceled/rejected. No simulated players or audible/rendered client acceptance.
