# 0.1.66

Dependency-only companion for Tavern 0.6.105. Both behavior and resource packs require the matching Tavern 0.6.105 UUIDs. World Liquor preserves public 0.1.58 gameplay, scripts, recipes, 56 shaker descriptors, 14 shaker recipes, furniture and assets; only paired dependencies and release/protocol identity advance. All owned UUIDs remain unchanged.

The earlier World Liquor 0.1.65 candidate remains frozen with its Tavern 0.6.103 dependencies and exact historical fingerprints. It is not reassigned to the revised pair. This release does not recover previously unpublished World Liquor functional changes.

The exact Tavern 0.6.105 source pin and paired validation remain pending until the corrected host source is publicly available. The earlier native white/gray result came from a synthetic external pure-red fallback probe; it is not evidence that reachable recipe atlas colors failed. All 250 reachable core/World Liquor colors are covered by the existing 336-color atlas. The host fallback for external out-of-domain RGB has a flat-shading limitation. This companion does not establish client acceptance. Static/data regression, BDS loading, saved-world rehearsal and human client acceptance remain separate gates.
