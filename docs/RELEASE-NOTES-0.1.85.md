Pair the existing World Liquor runtime with Tavern 0.6.119 at reviewed commit `6b0430b5befe4180e0895914abf9779a4567c401`. Both Tavern pack dependencies, World Liquor pack and module versions, the own resource dependency, payload version and package metadata advance together. The source-only ElbowStrike core, Java oracle, native observations and CI regressions merged in PR 57 remain included. This release does not install an ElbowStrike force adapter or claim that pending knockback, damage-phase or client parity is complete.

Validation covers the canonical release baseline and append-only history, reproducible guide and storage projections against the exact Tavern source, and exact package export. Full-family native loading, stopped-world migration and live deployment are recorded separately by the family workflow. Human client acceptance remains pending.
