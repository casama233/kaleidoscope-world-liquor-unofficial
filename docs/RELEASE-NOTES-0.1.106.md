# 0.1.106: pair the Tavern cocktail repairs

World Liquor's BP and RP now require Tavern 0.6.129 using the same verified
pack UUIDs. Both modules, the package version and the shared guide payload
advance together. Install both sides of both addons as a pair.

Tavern owns the repaired shaker ingredient gate, container delivery, clearing,
placed shaker carrier preservation, cocktail information, progress HUD and the
supported effect adapters. This release keeps World Liquor's registered
ingredients, recipes, effects, native item storage and seven-section guide
projection on that host. Grilling 2.8.117 remains an optional integration peer.

The exact host revision is recorded in `.github/baseline-integration.json`;
the existing remote package checks exercise its current guide, effect and
storage interfaces. A version pairing is not a new claim that World Liquor's
remaining Java or client gaps are repaired.

The source package remains a test release. Full-family native loading, a fresh
stopped-world rehearsal and admission are required for the standing-authorized
live update. No actual Player, rendered-client or LIVE acceptance is inferred
from source checks. `client=false` and `production_ready=false` remain in effect.
