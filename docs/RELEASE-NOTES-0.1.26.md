# 0.1.26 freezer / record repair

- 冰櫃補上 Java FreezerRenderer 的液面、有效配方原料（雪球、藍色染料、史萊姆球）與成品表面（冰、雪、熔岩）。開關蓋、取出、完成與區塊載入後定期同步；不改既有存檔內容。
- 自訂唱片在取出、挖除、爆炸、方塊被替換後停止播放。使用 32 個獨立聲道避免停止其他唱片機；既有存檔保留原有唱片。
- 唱片音場設定 64 格，近距離範圍 16 格，播放音量 4；实际听感仍需客户端验收。
- 禁止向已有原版唱片的唱片機塞入自訂唱片，亦不允許其他唱片覆蓋既有自訂唱片。
- 原生 BDS：四方向 × 五種液體及五種完成配方，共 40 顯示情境；空／關蓋清理、聲道分離與替換清理通過。未使用模擬玩家。畫面、聲音與真人操作未驗收。

來源：upstream 1.1.8-neoforge+1.21.1 的 FreezerRenderer 位元碼與 freezer 配方／材質。水與熔岩、三種原料材質來自 Mojang/bedrock-samples。
