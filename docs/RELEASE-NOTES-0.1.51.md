# World Liquor 0.1.51 — optional effect icon resources

Pairs with Tavern 0.6.87. Original effect sprites are unchanged. World Liquor now supplies its own additive icon panel, local cache and unique UI definition file, so Tavern alone no longer references absent World Liquor textures. The host hides inert saved addon effects when the addon is absent without deleting them.

No drink mechanics, recipes, saved IDs or original textures change. Both BP/RP dependency versions are synchronized. Static and native tests do not certify rendered client UI; human visual acceptance remains pending.
