# 0.1.33 — 冷凍機紅石控制

包含 0.1.32 的唱片與多段跳修復，新增 Java 對照紅石控制：通電開蓋、斷電關蓋並嘗試開始配方；製作中不能被通電強制開蓋，上方阻擋時不開蓋。保存電力狀態，重複回調或讀取相同電力不覆蓋玩家手動開關。

手動關閉和紅石關閉共用配方啟動規則，機器狀態／方塊狀態提交失敗會回滾。增加 6 項狀態測試及 5 項事件／故障注入測試。

仍未包含漏斗／流體側面自動化或比較器輸出；上方判斷沿用基岩 isSolid，並非 Java 全部紅石導體例外。配方與資產維持已鎖定的來源版本。不是全量 Java 一比一完成。

0.1.32 雲端 BSM 3.10.6／BDS 1.26.52.3 原生唱片探針已通過，四方向資料保留及支撐移除恰好四張掉落；0.1.33 結果另附。未通過客戶端、實際關服重啟或正式服存檔遷移驗收，禁止直接覆蓋正式服。
