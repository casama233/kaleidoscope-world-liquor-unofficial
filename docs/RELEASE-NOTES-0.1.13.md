# 0.1.13-preview.1 — 飲品表面與原作調酒條件

- 為 22 個飲品模型中 73 個重合雙面加入 0.02 模型單位的微小厚度，包含茅台瓶身飾帶；保留正反面的原作貼圖。
- 可樂、湯力水改列「調酒材料」。
- 14 筆調酒配方提供原作 Java 顏色標籤，由酒館共用 API 投影到廚房原生產品製作頁；指定物品槽位保留實際物品名稱，遊戲配方不變。
- 依賴酒館 0.6.50-beta.1，沿用其共用酒架命中處理。

已執行配對資源、三語指南檢查及隔離 BDS 載入，未模擬玩家。貼圖觀感與實際客戶端操作仍待驗收；本體九格酒櫃左右拿反尚不能宣稱根治。

需要廚房 1.0.6、酒館 0.6.50；備份後同步更新兩包的 BP/RP。
