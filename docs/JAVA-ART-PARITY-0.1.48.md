# 世界名酒 0.1.48：已固定版本的 Java 美術對齊

## 來源

本次以已核驗的 NeoForge 1.1.9 JAR 為來源；同時逐檔比對 Forge 1.1.11，選取的15份來源檔案位元組完全相同。
來源、JAR SHA-256及逐檔SHA-256留存在 `data/java-parity/neoforge-1.1.9/source.json`。
歷史 `upstream/source.lock.json` 仍如實保留1.1.8，不把整個舊來源冒稱成新版。

## 已完成

- 冰櫃關閉模型改為原版3個立方體、16個面；開啟模型保留10個立方體、44個面
- 更新兩份128×128冰櫃材質圖集為原版PNG；保留原版省略面、270°UV旋轉，安全烘焙180°UV端點
- 保留幾何識別碼、可視邊界、材質標籤、方塊狀態及物品各視角變換
- 更新冰櫃指南縮圖，避免仍顯示舊外殼；該縮圖仍是近似離線預覽，不宣稱原生GUI像素一致
- 另外11個共用幾何模型只移除原版已刪除的150個面（492→342）：凳子1個、酒櫃連接狀態8個、掛唱片2個
- 81個繼承來源變體共用上述11個形狀；其木種、顏色及唱片貼圖不變，不增加幾何ID
- 原本的模型雜湊保留作歷史證據；新版來源面清單與非UV欄位雜湊共同防止意外修改骨架、位置、邊界、材質或視角

## 檢查

`test_freezer_java_art.py`：6項檢查，直接從原版元素計算位置、尺寸、UV、旋轉與面清單。
`test_java_face_topology.py`：6項檢查，含故意破壞UV、座標、必要面及加入舊面的反例。
兩者與新來源檢查均接入正常發版檢查；既有歷史儲存、分類、拿取、配方與色彩檢查保持啟用。

已在官方 Blockbench 5.2.1 桌面版分別打開 Java 關閉模型及轉換後的基岩幾何。
基岩預覽使用與 canonical 檔案位元組相同的副本，手動匯入相同原圖；編輯器專用貼圖關聯不進入附加包。
已觀察帶貼圖的模型外形、第一人稱、第三人稱及GUI視角；Java與基岩預覽的模型姿勢和材質配置相符。
這不是 Minecraft 客戶端測試，也不等同於所有皮膚/FOV/光照下像素完全一致。
