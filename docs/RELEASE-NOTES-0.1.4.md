# 世界名酒 0.1.4 preview 1 — 指南重建

依賴 Tavern 0.6.39 及 Cookery 1.0.6；本附屬 BP/RP 均要更新。

66 個實物條目不再全部塞進附屬分類：18 個瓶裝酒、8 個調酒／調酒材料、16 張凳子、10 個儲酒櫃、1 台冷凍櫃、4 種食品、9 個藝術／唱片條目。每頁包含其真實做法、使用方式、實際材料替代選項與取出條件。

配方來自已註冊的 18 個酒桶配方、14 個雪克杯配方、5 個冷凍櫃配方及 39 個原生工作台配方。14 個調酒配方中，有 7 個給本體酒款；它們合併回本體原有酒款頁，不另建雜項頁。雞尾酒成品不再誤列成原料，品質 4–6 與每槽替代酒不再漏寫。

冷凍櫃顯示液體量、逐槽原料、數量、標稱加工時間及取出容器，布丁明列需要碗。有序合成另附位置圖與字母對照；唱片原生圖中的葡萄酒明確標為酒類標籤的示例，不把示例說成唯一材料。效果名稱與數值來自實際資料；未提供的輪廓效果不寫成已實現。

Cookery 1.0.6 的操作文字採完整繁中＋英文相容回退，名稱／分類保留三語；不修改宿主、不新增另一套指南書。本版未改附屬配方、效果表、物品、方塊、模型或材質，只改指南與套件版本／依賴。

執行 `python3 tools/rebuild_guide.py` 只重建指南；完整移植生成器也已接入這一步，避免下次生成回到舊錯誤。靜態驗證見 `GUIDE-VALIDATION-0.1.4.json`。未模擬玩家，未執行新的 BDS／客戶端；實際遊戲呈現仍需驗收。
