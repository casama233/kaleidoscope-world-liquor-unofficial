The owned scheduler registers only World Liquor-created ice and neighbors reached by its original branches. Dynamic data uses separate bounded512-cell pages per section, an independent game-tick clock and scheduling order; it never rewrites another addon's script or the vanilla frost definition. It preserves original first-request dedup, source state checks and queue restart. Script queries cannot load chunks; pending work pauses without inventing an age or deleting unavailable rows. Out-of-height neighbor reads use Java's air semantics. Expected unavailable neighbors defer a central melt rather than performing half its follow-up path.

Stable API brightness/height queries are used; named ticks or new experiments are not enabled. Actual scheduled-path Native proof remains separate from all event, lighting, RNG, full-family and human movement/art/audio acceptance. See release notes for explicit remaining gaps.
