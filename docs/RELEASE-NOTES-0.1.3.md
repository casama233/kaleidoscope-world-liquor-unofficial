# Kaleidoscope World Liquor (Unofficial) 0.1.3 preview 1

Requires Kaleidoscope Tavern (Unofficial) 0.6.37 beta 1.

- Furniture placement now follows Tavern's four-direction conversion.
- Sitting on World Liquor stools uses an invisible ride helper, removing the duplicate high stool model.
- Cabinets accept Tavern-managed quality bottle descriptions and can be used from their visible front face.
- The custom record displays a localized now-playing actionbar message.
- Creative entries use Tavern and Cookery family groups with one visible entry per quality drink.
- Fixed localized spruce/dark oak cabinet names; paintings identify their creator; the custom record has a localized name.

Static validation and isolated BDS load are recorded in `docs/VALIDATION-0.1.3.json`. Device rendering and interactions remain public-test items.
